# Motion Workbench 2.0 · Phase 2 变更报告（Motion Intelligence Recommendation）

> 目标：把「一句话需求」变成「可解释的 Top N 方案」。
> 本阶段新增一条纯规则的推荐链路：**一句话 → 五轴意图 → 加权打分 → Top N + 逐条理由 + 性能等级**。
> 既有的 60 个模板、组合方案、检索与助手一处没动，本页是新的入口。

---

## 一、这一阶段交付了什么

| # | 交付物 | 说明 |
| --- | --- | --- |
| 1 | **动效意图 `MotionIntent`** | 五个轴（场景 / 风格 / 情绪 / 性能 / 触发），每一轴都可空，另带「命中了哪些词」与一句复述 |
| 2 | **意图解析器 `MotionIntentParser`** | 词表驱动，五轴各自独立匹配；词表顺序即优先级，越具体的说法排越前 |
| 3 | **推荐服务 `MotionRecommendationService`** | 场景 40 / 风格 25 / 触发 18 / 情绪 15 / 性能 12，再加推荐指数加成（0-10）；性能等级 A / B / C |
| 4 | **推荐接口** | `POST /api/motion/templates/recommend`（`query` + `limit`，条数收敛在 1-20） |
| 5 | **推荐结果 `MotionRecommendVO`** | 每条带：key / 名称 / 分组 / 模板自己的场景与风格 / 技术 / 触发 / 运行档位 / 性能等级 / 本次得分 / 推荐指数 / 星级 / 命中轴 / 逐条理由 |
| 6 | **三栏推荐页 `MotionRecommendView`** | 左：输入需求（7 个示例说法、条数选择、识别结果解读）｜中：推荐方案 Top N｜右：效果预览 + 为什么推荐它 + 可直接复用的提示词 |
| 7 | **入口与路由** | 工作台右上角「智能推荐」；`/extensions/motion-lab/recommend` |

## 二、评分口径（写死在代码里，可复现）

| 轴 | 权重 | 判据 |
| --- | --- | --- |
| 场景 | 40 | 与模板 `scene` 相同 |
| 风格 | 25 | 与模板 `style` 相同 |
| 触发 | 18 | 与模板 `trigger_type` 相同 |
| 情绪 | 15 | 情绪词表命中模板的风格 / 分组 / 标签 / 名称 / 说明 |
| 性能 | 12 | 与预算对应的档位一致（轻量优先 → 轻量档，效果优先 → GPU 档） |
| 推荐指数加成 | 0-10 | 模板自身推荐指数 ÷ 10 四舍五入，用来定同分者的次序 |

- **不命中的轴不加分也不扣分**：说不清的轴不该把合适的东西压下去。
- **性能轴是唯一的例外**：用户明说「轻量优先」时，依赖 GPU 的模板扣 8 分并在理由里写明原因 —— 只是排后面，不会被藏起来。
- **性能等级**由运行档位与性能子分算出：轻量档且性能子分 ≥ 92 是 A，轻量档其余与均衡档是 B，依赖 GPU 是 C。

## 五、实测中修掉的两个问题

**一、排序方向被 `.reversed()` 翻了过来。**
比较器写成 `按分数倒序().thenComparing(推荐指数).reversed()` —— `reversed()` 作用于**整个**比较器，
于是分数也一起被反过来，分数最低的会排第一。改为两级各自反一次，并用测试把顺序钉死。

**二、卡片上的场景 / 风格显示成了「用户要求的那个」，而不是模板自己的值。**
推荐「游戏登录页面」时，一条属于「AI 产品页」的模板也在卡片上写着「登录页面」，
看上去像它真的属于登录页。现在卡片显示模板自己的场景与风格，命中关系只写在理由里 —— 一个说「它是什么」，一个说「它为什么被选中」。

## 六、这条链路的边界

**第一版刻意不接模型**（spec 要求规则 + 权重）：同一句话任何时候解析结果都一样，界面上还能指出是哪个词触发的。
Phase 4 的 AI Motion Designer 会复用同一套五轴 `MotionIntent` 与同一套打分 —— 模型只负责把更自由的说法翻译成这五个轴，推荐与解释不用改。

**情绪轴读的是模板可解释的文本字段**（风格 / 分组 / 标签 / 名称 / 说明），不是语义向量。
模板里没有「高级感」这类对应词时，这一轴就命中不了 —— 宁可少加 15 分，也不猜。

**推荐只排序、不隐藏。** 任何不适配的模板只是排到后面，理由里说明原因；预算不合的还会明说「已往后放」。
